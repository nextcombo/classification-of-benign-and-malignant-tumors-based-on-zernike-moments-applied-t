# Classification of benign and malignant tumors based on Zernike moments applied to breast cancer diagnosis - Rapidly-weighted learning rules (Mtlab code implementation)

[Classification of benign and malignant tumors based on Zernike Moments]Rapidly learning rules for breast cancer diagnosis (Mtlab code implementation)
When the main function is run, it calculates the Zernike moments of the input image, where n=4 is the order and m=2 is the repetition. Since the first row of images is a rotational version of a unique object (an ellipse), the magnitudes of the Zernike moments for these three images are identical. Additionally, the phase difference of the moments is proportional to the rotation angle of the image. As expected, the Zernike moments for two different shapes (for example, an ellipse and a rectangle) are completely different. This behavior is due to the capability of Zernike moments in describing the shape of an object.
F. Saki, A. Tahmasbi, H. Soltanian-Zadeh, S. B. Shokouhi, Fast opposite weight learning rules with application in breast cancer diagnosis, Comput. Biol. Med., vol. 43, no. 1, pp. 32-41, 2013.
